> This is an unofficial Japanese translation. It does not contain the tool itself.

`cargo vet` サブコマンドは、サードパーティの Rust の依存が、信頼できる主体によって監査されていることをプロジェクトが確認できるようにするためのツールです。軽量で、導入しやすいことを目指しています。

詳しくは[ガイド](https://rustsecjp.github.io/cargo-vet-ja/)を見てください（原文: [book](https://mozilla.github.io/cargo-vet/)）。
